# 崇祯直聘 · 原生 Android 单机版

- 安装包：`崇祯直聘-0.5.0-debug.apk`
- 包名：`com.chenbenkong.chongzhen`
- 版本：`versionName 0.5.0` / `versionCode 1`
- 最低系统：Android 8.0（API 26），目标 API 35
- 大小：18,880,144 字节
- SHA-256：`F8AFC959356B8D4C720CB05F13048BC2E7F6E1C47C066ABF416FBA575767DFCF`

## 安装

1. 把 APK 传到 Android 手机或平板；
2. 在系统设置里允许对应文件管理器 / 浏览器「安装未知应用」；
3. 点开 APK 安装。若此前装过同包名但签名不同的版本，先卸载旧版；
4. 启动即进入强制横屏。Manifest 为 `sensorLandscape`，`MainActivity` 启动/回前台时再请求一次
   同一方向，不依赖系统「自动旋转」开关，也不受用户竖屏锁定影响。

这是 **debug 签名** 的本地安装包，不用于应用商店；release 签名尚未配置。包内已打入
`assets/game-data.json`（3,927,505 字节）和 `res/raw/bgm.mp3`（5,984,756 字节），
运行时不联网，Manifest 不申请 `INTERNET`。

## 本次重做（2026-11-17）

- **手机默认单栏**：不再让个人能力、五方态度两栏常驻挤占事件区；844/924dp 宽度的手机，
  事件卡直接拿回整块宽度。只有 ≥600dp 高的平板/桌面才显示三栏。
- **可开合「面板」抽屉**：顶栏保留「国势 + 面板」；点「面板」从右侧打开抽屉，三个页签
  **能力 / 态度 / 卷宗**，点遮罩、关闭按钮或系统返回键收起。能力页含
  **财帛 / 文韬 / 理政 / 武略 / 体质** 与隐藏属性；**属性用三列紧凑格、只显示名目和数值，
  不再画横向长条**。卷宗含票签、履历、结局图鉴。
- **财帛/体质速览**：顶栏国势左侧直接显示「财帛 N · 体质 N」，不打开面板也能看到两个致命项。
- **选项不再埋在正文底部**：事件标题右侧固定「选项 N」，点开全屏抉择面板；四个选项一次看全，
  不用先划过整篇叙事。**正文底部不再重复铺选项**。标题下的待办重复行已删，数量只在「操作 N」角标显示。
- **底部操作条默认收起**：不再常驻占掉整行高度；顶栏「面板」右侧只留一个 44dp 的「操作」入口，点开才浮出
  「标题 / 撤销 / 存档 / 进下月 / ×」，点遮罩、× 或系统返回键收起。收起态事件区没有底部遮挡。
- **正文与选项缩小一档**：事件描述 14sp→12.5sp，引语与选项正文同步降档，手机上不再“一行没几个字”。
- **顶栏减负**：回合/待办只在展开的操作条里出现，不再和姓名、官职抢顶部空间。
- **开局三屏不再占高**：取名屏姓/名/字/年岁同一排、籍贯与随机抽同排、两个按钮同排，
  删除重复预览与底部返回；出身屏 8 张卡默认只露名称、官阶和「详情 / 选此」，
  背景、标签、玩法与五围默认收起，属性改成紧凑值块、不再画横条；标题屏难度横排、按钮横排。
  原生 `NameSetupScreen` / `OriginSelectScreen` / `TitleScreen` 同步重排。
- **结算不再重播正文**：点完选项后只显示刚选的选项、结果评价、属性增减与回音，
  事件标题和整篇事件正文不再出现。手机 Web 用作用域 CSS 隐藏；原生在结算态直接不渲染
  `EventCard`，只渲染 `OutcomePanel`。
- **原生 BGM**：之前 APK 完全没有音频；现在把 5,984,756 字节的 `bgm.mp3` 打进 `res/raw`，
  `MediaPlayer` 循环播放、默认开，标题屏与底部操作条各有一个 44dp「乐 / 静」开关；
  切后台暂停、回前台续播，音频焦点被别的应用抢走时暂停或降音量。
- **强制横屏**：`sensorLandscape` + 运行时二次请求，允许左右两个横屏方向；正常 Android 上
  系统竖屏锁定不会再把牌桌转成竖屏。
- **视觉仍对齐桌面 Web**：墨黑渐变底、旧金 `#C5A55A`、宣纸正文、3dp 方角、1dp 细线、系统宋体；
  系统状态栏/导航栏已沉浸式隐藏，顶部不再出现一条纯黑空栏。

## 追加修复（2026-11-17 晚）

- 骰子投失败的自动回音改为按选项意图生成：上疏请饷、弹劾、护送太子、赈灾、科举等
  不再被套进“你自恃能武，执意出战 / 兵卒折损数十”的军事模板；Web 与原生 APK 使用同一口径。
- 失败副作用不再无条件“道德值 -2 / 野心值 +2”；只有成功效果明确带正向道德值时，失败才按比例扣回。
- 原生 `FailFallback.kt` 已同步重写并重新编译；APK 已重建，SHA-256 见上。
- **换皮事件不再同局撞车**：`gray_debauchery_001`（《下属献妻》）与
  `gray_debauchery_020`（《县丞献妻》）共用 `exclusiveGroup`，一局只发其中一张；
  《画舫春宵》拆成《秦淮画舫》/《盐商画舫》并同组互斥；《天命所归》灰线改题
  《妖道献谶》，《东窗事发》拆成《外室事发》/《正妻捉奸》。Web 与原生事件池
  都从 `eventHistory` 反查互斥组，读档后仍然生效。
