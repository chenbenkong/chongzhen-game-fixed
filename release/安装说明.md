- SHA-256：`E56C9902284459731BCF794DFF200AD44DCF61ACBE3B479074FC47FC8FEA614C`

## 安装

1. 把 APK 传到 Android 手机或平板；
2. 在系统设置里允许对应文件管理器 / 浏览器「安装未知应用」；
3. 点开 APK 安装。若此前装过同包名但签名不同的版本，先卸载旧版；
4. 启动即进入强制横屏。Manifest 为 `sensorLandscape`，`MainActivity` 启动/回前台时再请求一次
   同一方向，不依赖系统「自动旋转」开关，也不受用户竖屏锁定影响。

这是 **debug 签名** 的本地安装包，不用于应用商店；release 签名尚未配置。包内已打入
`assets/game-data.json`（3,927,111 字节），运行时不联网，Manifest 不申请 `INTERNET`。

## 本次重做（2026-11-17）

- **手机默认单栏**：不再让个人能力、五方态度两栏常驻挤占事件区；844/924dp 宽度的手机，
  事件卡直接拿回整块宽度。只有 ≥600dp 高的平板/桌面才显示三栏。
- **可开合「面板」抽屉**：顶栏保留「国势 + 面板」；点「面板」从右侧打开抽屉，三个页签
  **能力 / 态度 / 卷宗**，点遮罩、关闭按钮或系统返回键收起。卷宗含票签、履历、结局图鉴。
- **底部操作条默认收起**：不再常驻占掉整行高度；右下角只留一个 44dp 的「操作」入口，点开才浮出
  「标题 / 撤销 / 存档 / 进下月 / ×」，点遮罩、× 或系统返回键收起。事件区因此多出约 56dp 正文高度。
- **正文与选项缩小一档**：事件描述 14sp→12.5sp，引语与选项正文同步降档，手机上不再“一行没几个字”。
- **顶栏减负**：回合/待办只在展开的操作条里出现，不再和姓名、官职抢顶部空间。
- **强制横屏**：`sensorLandscape` + 运行时二次请求，允许左右两个横屏方向；正常 Android 上
  系统竖屏锁定不会再把牌桌转成竖屏。
- **视觉仍对齐桌面 Web**：墨黑渐变底、旧金 `#C5A55A`、宣纸正文、3dp 方角、1dp 细线、系统宋体；
  系统状态栏/导航栏已沉浸式隐藏，顶部不再出现一条纯黑空栏。
